Chapter 2

Set Up GitHub

GitHub is where the project code lives. You'll need an account to get your own copy of the project, and Git installed on your computer to work with it.

Create a GitHub Account

1 Go to the GitHub sign-up page
https://github.com/signup
2 Create your account

Enter your email address, create a password, and choose a username. This username will be visible on your projects, so pick something you're comfortable with.

3 Verify your email

GitHub will send a verification email. Open it and click the link to confirm your account.

Install Git

4 Download Git for Windows
https://git-scm.com/downloads

Click Windows and download the installer.

5 Run the installer

Double-click the downloaded file. Accept all the defaults — just keep clicking Next until it finishes. The default settings are fine for everything.

Set Your Identity

6 Open a terminal

Press the Windows key, type cmd, and press Enter to open Command Prompt.

7 Tell Git who you are

Type these two commands, one at a time, using your own name and the email you used for GitHub:

git config --global user.name "Your Name"
git config --global user.email "your@email.com"

This attaches your name to your work — it's how Git labels who made each change.

8 Verify it worked

Type this command:

git --version

You should see a version number like git version 2.47.0. If you see "command not found", restart your terminal and try again.

Stuck?
Ask Claude in your browser tab! Paste the error message and say what step you're on. Claude has helped thousands of people set up Git.
Good to know
GitHub is free for public and private projects. No subscription needed.
Chapter 3

Install Visual Studio Community

Visual Studio Community is a free, full-featured IDE from Microsoft. It's where you'll write code, run the app, and manage your project.

Download the Installer

1 Open the Visual Studio download page
https://visualstudio.microsoft.com/vs/community/
2 Click "Download Community"

A small installer file will download (about 2 MB). It's called something like VisualStudioSetup.exe.

3 Run the installer

Double-click the downloaded file. If Windows asks "Do you want to allow this app to make changes?", click Yes.

Choose Your Workloads

The installer shows a screen of "workloads" — bundles of tools for different types of development. Select these three:

4 Select ".NET Desktop Development"

This is the foundation. It includes everything you need to build desktop apps with Avalonia UI — which is what the Kuwantima project uses.

5 Select ".NET Multi-platform App UI Development"

This adds mobile development support (Android and iOS). We'll use this later with Avalonia Mobile to bring designs to phones and tablets.

6 Select "ASP.NET and Web Development"

This adds web development tools including Blazor — Microsoft's framework for building interactive web apps with C#. Blazor will be your first web project, so having this ready from the start saves you a trip back to the installer later.

7 Click "Install"

With three workloads selected, this will download several gigabytes of tools. It takes 15-40 minutes depending on your internet speed. You can use your computer while it installs.

Tip
If the download seems stuck, it's normal — the progress bar sometimes pauses on large components. Give it time.
Why three workloads?
Each workload prepares you for a different platform:
Desktop = Windows apps (Kuwantima lives here)
Mobile = Android/iOS apps (where we're headed next)
Web = Blazor web apps (your first solo project path)
All three use C# and .NET, so the skills transfer between them.

First Launch

8 Open Visual Studio

When installation finishes, click Launch. Visual Studio will ask you to sign in with a Microsoft account. You can:

  • Sign in with an existing Microsoft/Outlook/Hotmail account
  • Create a free Microsoft account
  • Click "Not now, maybe later" to skip (you'll need to sign in within 30 days)
9 Pick a color theme

Visual Studio asks you to pick a theme (Dark, Blue, or Light). Pick whatever feels comfortable — you can change this later in Tools > Options > Environment > General.

10 Verify it works

You should see the Visual Studio Start Window with options like "Clone a repository", "Open a project or solution", etc. If you see this, you're all set!

Install the Avalonia Extension

Avalonia is the UI framework Kuwantima is built on. This extension adds project templates, a visual previewer, and IntelliSense for Avalonia AXAML files.

11 Open the Extensions menu

In Visual Studio, go to Extensions > Manage Extensions.

12 Search for "Avalonia"

In the search box, type Avalonia. Look for "Avalonia for Visual Studio" by AvaloniaUI.

13 Download and restart

Click Download, then close and reopen Visual Studio to complete the installation.

Good to know
Visual Studio Community is completely free for individual developers, students, and open-source projects. No trial period, no limitations for our use.
Chapter 4

Add Claude to Visual Studio

Now we'll install the Claude extension so you can use it directly inside Visual Studio while you work.

Install Claude Code CLI

The Claude extension for Visual Studio is built on top of Claude Code, a command-line tool that needs to be installed first.

1 Install Node.js

Claude Code requires Node.js to run. Download the LTS version from:

https://nodejs.org

Run the installer and accept the defaults. When it finishes, restart your terminal.

2 Install Claude Code

Open Command Prompt and run:

npm install -g @anthropic-ai/claude-code

This installs the Claude Code CLI globally on your machine.

3 Verify it installed

Run this command:

claude --version

You should see a version number. If you get "command not found", close and reopen your terminal.

4 Sign in to Claude

Run:

claude

The first time you run it, it will open your browser to sign in. Log in with the same account you subscribed with in Chapter 1. Once authenticated, the browser will confirm success and you can return to your terminal.

Install the Visual Studio Extension

Now we'll add the extension that brings Claude into Visual Studio's interface. This is a community extension called Claude Code Extension by dliedke — it's the most popular and mature Claude integration for Visual Studio, with over 72,000 installs.

5 Open Visual Studio

Launch Visual Studio if it isn't open already.

6 Open the Extensions menu

In the top menu bar, click Extensions, then click Manage Extensions.

7 Search for "Claude Code Extension"

In the search box on the right, type "Claude Code". Look for "Claude Code Extension" by dliedke.

8 Click "Download"

Click the Download button. Visual Studio will tell you the extension will be installed after you close and reopen it.

9 Restart Visual Studio

Close Visual Studio completely, then reopen it. The extension will finish installing during startup.

Verify Everything Works

10 Open the Claude panel

Go to View in the top menu bar. Look for "Claude Code" and click it. A Claude panel will appear, usually on the right side of the screen.

11 Test it out

In the Claude panel, type:

Hi, what can you help me with?

If Claude responds, you're all set! The extension uses your Claude Code CLI login from step 4, so no separate sign-in is needed.

If the panel says "Claude Code not found"
This means the CLI from steps 1-3 isn't on your system PATH. Close Visual Studio, open a new terminal, run claude --version to confirm it works there, then reopen Visual Studio.

How to Use Claude in Your Work

Claude is your always-available coding partner. Here are the most useful things it can do:

Ask questions about the project

Open a file, then ask Claude things like "What does this file do?" or "How does the theme system work?" — Claude can see the files in your project.

Get help with errors

If you see a red error squiggle or a build error, ask Claude "What does this error mean?" and paste the error message. It will explain the problem and suggest a fix.

Learn as you go

When you encounter unfamiliar code, ask Claude to explain it. For example: "What is a DataTemplate?" or "Why does this use DynamicResource instead of StaticResource?"

Get unstuck

Any time you hit a wall — something won't build, a style isn't applying, you're not sure what to do next — just describe what's happening to Claude. It can read your project files and give you specific, step-by-step guidance.

Best practice
Think of Claude as a conversation partner, not a search engine. The more context you give it ("I'm trying to change the button color but I'm not sure which file to edit"), the better its answers will be.

Things to Try Asking Claude

Once you've set up the project (next guide), here are some great first questions to ask Claude in the Visual Studio panel:

Understanding the project
  • Can you give me an overview of how this project is structured?
  • What files would I change to modify a button's appearance?
  • How do the light and dark themes work?
Learning C# and AXAML
  • I'm new to C# — can you explain what this code does in simple terms?
  • What is AXAML and how does it relate to the C# code?
  • What does "binding" mean in this context?
Getting started with Blazor
  • I want to create my first Blazor project — can you walk me through it?
  • What's the difference between Blazor Server and Blazor WebAssembly?
  • How do I add a new page to a Blazor app?
When you're stuck
  • The build failed with this error — what does it mean? [paste error]
  • I changed a color but nothing happened — what am I missing?
  • I'm not sure what to work on next — what would you suggest?
Remember
There are no bad questions. Claude has infinite patience and never judges. If something doesn't make sense, ask it to explain differently — try "Can you explain that in simpler terms?" or "Can you show me an example?"
Two Claudes are better than one
Keep claude.ai open in a browser tab as a second Claude. Use the one in Visual Studio for project questions (it can see your code) and the browser one for general learning — "what is AXAML?", "explain this error message", or "how do CSS-like selectors work in Avalonia?" The browser version is great for longer back-and-forth conversations when you're exploring a concept.
